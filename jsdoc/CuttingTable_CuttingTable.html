CuttingTable

CuttingTable(element, urlInputopt, gridSelectoropt, downloadopt, autoLoadopt, urlsopt, shiftsopt)

Constructor

# new CuttingTable(element, urlInputopt, gridSelectoropt, downloadopt, autoLoadopt, urlsopt, shiftsopt)

Initializes a new CuttingTable instance for interactive image cutting and visualization.

Parameters:
Name Type Attributes Default Description
element HTMLDivElement

The container element where the CuttingTable interface will be rendered.
urlInput boolean <optional>
 true

Whether to display a URL input field for specifying image sources.
gridSelector boolean <optional>
 true

Whether to enable grid selection controls for layout configuration.
download boolean <optional>
 true

Whether to enable download functionality for exported JSON data.
autoLoad boolean <optional>
 true

Whether to automatically load the first configured URL upon initialization.
urls URL | Array.<{url: string, label: string}> | string | undefined <optional>

Optional initial URLs to load. Can be a single URL, an array of URL objects with labels, or a string URL.
shifts boolean <optional>
 false

Whether to enable shift controls for offset adjustments.

If no valid element is provided or if no initial URL is set when urlInput is false.

Error
Examples
const container = document.getElementById("cutting-table");
const cuttingTable = new CuttingTable(container, true, true, true, true, "https://example.com/iiif/image/info.json");
const cuttingTable = new CuttingTable(container, false, true, true, true, [
  { url: "https://example.com/iiif/image1/info.json", label: "Image 1" },
  { url: "https://example.com/iiif/image2/info.json", label: "Image 2" }
]);
